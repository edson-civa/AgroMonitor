# AgroMonitor

Projeto desenvolvido para a disciplina de Programação Orientada a Objetos utilizando a linguagem Eiffel.

## Descrição

O sistema simula uma estufa inteligente capaz de monitorar temperatura e umidade, além de controlar automaticamente a irrigação e emitir alertas quando necessário.

## Funcionalidades

- Monitoramento de temperatura
- Monitoramento de umidade
- Controle de irrigação
- Alertas de temperatura
- Exibição de status da estufa

## Conceitos de POO utilizados

- Herança
- Composição
- Encapsulamento
- Construtores
- Polimorfismo (sobrescrita)
